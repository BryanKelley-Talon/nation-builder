governance-pole and advisor text — is a **separate work** from the Nation Builder
game code. It is data the game loads at runtime.

**Holder:** Flashpoint History

The game code in the rest of this repository is licensed differently: GNU GPL v3
with additional terms (see `../LICENSE`). No file in this repository carries both
licenses.

Each scenario file repeats its license in a `license` object
(`name`, `url`, `holder`, `sellable`). Content sourced from third-party material
must name that source and its terms in the same object; `sellable` is `true` only
when every source allows sale.
